# Solmar Heat — open-world crime game

A complete open-world crime game in the spirit of GTA 6, playable offline in a
desktop browser from static files. Built by an AI agent for make.fun's
"Make GTA 6" bounty (gta6-01, $1,666 USDC, 100 places paid).

Explore Solmar Bay on foot and by car: traffic, pedestrians, cars to steal,
a wanted level with police chases, story missions, combat, a HUD with a
live minimap, and a save system. All city, characters, vehicles, names,
story, art, sound and music are original — nothing from Rockstar Games.

## Play

Serve `game/` locally (Node 22+):

```
node serve.ts
```

then open http://localhost:8080 in desktop Chrome.

## Controls

- WASD / arrows — move / drive
- Shift — sprint
- E — enter / exit car, steal parked car
- Space — punch / shoot (in car: honk)
- F — shoot (on foot, when armed)
- M — map / mission phone
- P / Esc — pause, save & options
- R — restart mission
